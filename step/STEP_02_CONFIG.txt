STEP 02 — CENTRAL CONFIG.INI SYSTEM

Continue the existing project:
E:\website\_ep9

Do not rebuild from scratch.

Create:
E:\website\_ep9\config.ini

This is the MOST IMPORTANT requirement.

The website must be reusable for different RAN Online servers.

All server-specific information that normally changes between servers must come from ONE config.ini.

Include at least:

[SERVER]
Name=My RAN Online
ShortName=MYRAN
Version=EP9

Description=Experience a new RAN Online adventure.

MaxRebirth=30

Implement a real config loader. If the chosen frontend cannot directly read .ini at runtime, use a practical build-time configuration approach while keeping config.ini as the single editable source.

Replace hard-coded server information in the UI with config values.

Test by changing server name, tagline, max level, download URL and Discord URL, then build again and verify the website uses the changed values.

No undefined/null values should appear.

Finish this step completely.
